# Calculadora — AI-Native 10× Standard

## Product thesis
Calculadora should stop behaving like a directory of individual calculators. It should behave like a bilingual decision assistant that understands the user's situation, runs the right calculations automatically, remembers assumptions, compares scenarios, and recommends the next calculation.

## Autonomous job
**Question → Scenario Pack**
A user can type or speak a natural-language goal such as: “Can I afford this house?” or “Should I refinance, pay debt, or invest the extra cash?” Calculadora should identify the required calculators, ask only for missing inputs, run the scenarios, show the assumptions, and compare outcomes.

## Persistent memory
With user control, remember:
- language, locale, currency and units
- recurring income/expense assumptions
- property/project assumptions
- saved scenarios
- preferred financing ranges
- prior calculations and comparison choices

## 10× interaction
One request should replace manually finding and completing 3–6 separate calculators.

## Proactive next step
After every result, show the one most relevant next calculation or connected portfolio asset instead of a generic link wall.

## ROI metrics
- time from landing → completed useful answer
- calculations automatically chained per session
- saved-scenario return rate
- bilingual usage and completion
- lead/affiliate conversion from contextually relevant offers
- SEO landing page → interactive tool activation rate

## Weekly punch list
1. natural-language calculator router
2. saved assumptions / scenario memory
3. compare-three-scenarios view
4. voice input
5. contextual cross-links to Best Quote, QuickBid, Real Deals, RoofCast and TradeSherpa

## Guardrails
Show formulas/assumptions. Never disguise estimates as guaranteed outcomes. Sponsored offers must stay visibly separate from mathematical results.

## Brett Adcock principles applied
Build the 10× workflow, use memory, remove repetitive clicking, rapidly prototype scenario flows, and measure whether the system saves meaningful time rather than adding another calculator page.
